Building a Course with This Template

From an empty folder to a finished course website in the university’s corporate design

Author

Digitalisierungszentrum, Universitätsmedizin Göttingen

Published

20 September 2026

You know your subject and you want to teach it online. What you do not want is to learn web design, or to argue with a learning platform’s editor about where a picture goes.

This template turns plain text files into a complete course website: chapters with a sidebar, search, self-check quizzes, lecture slides, a dark mode, and a layout that works on a phone. Colours, typeface and logo placement already follow the Universitätsmedizin Göttingen corporate design, so nobody has to decide them again.

This course is built with the template it teaches. Every feature you read about is in use on the page in front of you, and the files behind these pages are the worked examples. When a chapter says “see how it is done”, open the matching .qmd file and look.

By the end of this course you will be able to

  • Install the software and build your first course website from the template
  • Plan a course as chapters with objectives that can be checked
  • Write content: headings, images, tables, callouts, diagrams, references
  • Add self-check questions that give learners immediate feedback
  • Prepare lecture slides and run a checklist before release
  • Publish the course on GitHub or GitLab Pages, and update it later

How this course works

There are eight short chapters, in four groups. Each has the same shape: objectives at the top, explanation with examples, and questions at the end. Plan on about three to four hours in total, and take them in order the first time. You can stop after any chapter and come back.

If you are in a hurry: Chapter 1 gets you a running project, Chapter 7 is the checklist, and Chapter 8 gets the course online. Everything in between is what makes the course good.

Try it now

Every chapter ends with questions like this one. Choose an answer and press Check answer; the page tells you whether you were right and why. Nothing is recorded anywhere, so guessing costs you nothing.

In this template, what does one chapter correspond to?

Each chapter is a single .qmd file: plain text with a small amount of markup. The navigation file only lists the chapters and puts them in order. Chapter 2 covers how the two fit together.

Some questions ask for a word instead. The tool that turns the text files into a website is called ? (type it in and click elsewhere).

Before you start

What you need

R and RStudio, both free. RStudio includes Quarto, the tool that builds the website, so there is nothing else to install. You will not write or run any R code: R is simply what RStudio runs on. A modern web browser is all a reader needs.

Using this as your starting point

Chapter 1 explains exactly how to copy this project and turn it into your own course. In short: duplicate the folder, replace the chapters, change a handful of lines in one settings file.
