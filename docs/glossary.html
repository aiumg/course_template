Glossary

Every technical word used in this course, in plain language

Terms are listed alphabetically. The right-hand column says where the term is explained in context.

Term Meaning Chapter
Alt text A written description of an image, read aloud by screen readers and shown when the image cannot load 4
Callout A coloured box for a note, tip, warning or similar remark 3
Commit A saved, labelled snapshot of your changes in a repository 8
Docs folder (docs) The folder where the finished website is written. It is what gets published 1, 8
GitHub / GitLab Websites that store projects online and can also show their web pages to the public 8
Markdown A way of formatting text with a few plain symbols, such as ## for a heading and ** for bold 3
Mermaid A tool that draws a diagram from a short text description 4
Pages The GitHub and GitLab feature that shows the files of a repository as a website 8
Push Sending your commits from your computer to the online repository 8
.qmd file A text file holding one chapter. The extension stands for “Quarto markdown” 1
Quarto The program that turns the text files into a website. It is included in RStudio 1
R The engine that RStudio runs on. You do not need to write R code for this template 1
Render To build the website from the text files. In RStudio: the Render Website button 1
Repository A project folder stored online together with the history of its changes 8
RStudio The program in which you write the course and press Render 1
Sidebar The chapter list on the left of every page; set in _quarto.yml 2
Source / Visual mode The two views of the RStudio editor: plain text with symbols, or a word-processor look 1, 3
Speaker notes Notes on a slide that only the presenter sees 6
Task list A bullet list with checkboxes; here it is how quiz options are written 5
WCAG The Web Content Accessibility Guidelines, the standard for accessible websites 7
YAML (.yml) A strict, indentation-based settings format. _quarto.yml is written in it 2
